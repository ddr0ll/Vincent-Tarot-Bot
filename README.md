# ИИ Таролог на Вашем Сервере

## Discord-бот с раскладами Таро, ежедневными предсказаниями и интерактивными командами для гадания.

| Характеристика | Технология / Описание                                              |
| :--- |:-------------------------------------------------------------------|
| ⚙️ **Основа бота** | `discord.py`                                                       |
| 🎨 **Стилизация сообщений** | `discord.ui`                                                       |
| 🎛️ **Интерфейс** | Discord Message Components V2                                      |
| 🧠 **ИИ Агент** | [Kimi-K3](https://build.nvidia.com/moonshotai/kimi-k3) |
| ⚡ **Асинхронные запросы** | `aiohttp`                                                          |
| 💾 **Работа с файлами** | Временные файлы обрабатываются через ОЗУ (Memory Buffer)           |

# ✨ Vincent's Tarot v2.1

## ♻️ Нововведения и Рефакторинг
* **Brain Swap: Встречайте, [Kimi-K3](https://build.nvidia.com/moonshotai/kimi-k3)!** Ответы стали глубже, быстрее, точнее и кинематографичнее.
* **Еще быстрее: Интерактивная кнопка «🃏Трактовка»** - Обработка выпавших карт начинается заранее, что ускоряет взаимодействие!
* **Деликатный вопрос?** - Добавлена возможность **скрыть** ответ в Эфимерном Сообщении.
* **Техническая часть: Появилась модульная система на базе `InitialView`, `LoadingView` и `FinalView`.**
* **Защита от чужого любопытства:** В `v2` добавлен строгий `interaction_check`.</br>Больше никто не сможет нажать кнопку в *твоём* личном раскладе. Попытка залезть в чужую судьбу вернет лаконичное: **`❌ Это не твой расклад!`**.

# Команды Бота
```text
/tarot
    ├── daily - Расклад на одну карту Таро с предсказанием на день.
    │
    ├── ask - Расклад на одну карту Таро с возможностью задать вопрос Картам.
    │
    ├── trio - Расклад на три карты Таро с возможностью задать вопрос Картам.
    │
    └── love - Расклад на шесть карт на тему Отношений, с возможностью задать вопрос Картам.

/ball
    └── Магический Шар - Задайте вопрос, на который можно ответить да или нет, и позвольте духам (или рандому) решить.

/docs tarot
    └── Краткая документация команд.
```

# Setup: Настройка .env файла:

| Переменная                                                | Описание / Значение                                                           |
|:----------------------------------------------------------|:------------------------------------------------------------------------------|
| `TOKEN`                                                   | Токен вашего Discord-бота                                                     |
| `INVOKE_URL`                                              | URL-адрес эндпоинта API от Nvidia для отправки запросов к модели.             |
| `AUTHORIZATION`                                           | Ключ авторизации (API Key) для доступа к нейросети Kimi 2.6 через хаб Nvidia. |
| `TAROT_COMMAND_ID`                                        | Уникальный ID глобальной слэш-команды бота. Необходим для интеграции UI.      |
>* **Как узнать ID команды:** ID станет доступен сразу после первого запуска бота.</br>Просто перейдите в **Настройки Discord > Интеграция** (или кликните правой кнопкой мыши по любой команде группы Таро в чате) и выберите **«Скопировать ID»**.
>
>* **Где взять ключи:** Зарегистрируйтесь на [NVIDIA BUILD](https://build.nvidia.com/), чтобы бесплатно получить API-ключ для [Kimi 2.6](https://build.nvidia.com/moonshotai/kimi-k2.6/modelcard) и актуальный Invoke URL.
